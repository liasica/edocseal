# 签约企业与证书

合同签署时，edocseal 在 PDF 上加两处签名：企业签名（当前签约企业的证书与签章）和个人签名（签约人的证书与手写签名）。本文说明证书生成方式、各类证书的签发、复用与自动续签规则，以及签约企业的管理方式。

管理入口为管理后台「系统设置 -> 签约证书」，包括证书生成方式、签约企业与证书详情。

## 证书生成方式

| 取值 | 含义 |
| --- | --- |
| `SELF` | 自签：由签约企业自己的根证书签发 |
| `SNCA` | 陕西CA：向陕西CA 申请 |
| `SNCA_V2` | 陕西CA 新接口：尚未对接，收到该值时签约返回「不支持的证书生成方式」 |

生成方式保存在 aurservd 的设置项 `CERTIFICATE_ISSUER`，签约时通过 `Sign` 请求的 `certificate_issuer` 原样传入。请求未携带时按配置项 `selfSign` 决定：`true` 为 `SELF`，否则为 `SNCA`。

## 签约企业

签约企业在「签约证书」页面管理，操作经 aurservd 调用本服务的 `EnterpriseService`，立即生效，无需重启：

- 新增或修改：统一社会信用代码（18 位）、企业名称、省份、城市、代办人姓名／手机号／身份证号（向陕西CA 申请企业证书时必填）、签章图片（PNG）。修改时不上传签章则保留原签章；修改企业信息不影响已签发的证书，续签后的证书使用新信息。
- 设为签约企业：合同的企业签名使用当前签约企业；第一个新增的企业自动成为签约企业。
- 删除：当前签约企业不能删除；删除时一并删除其证书记录与签章文件。
- 证书展示：只展示当前证书生成方式的证书，自签展示企业根证书与自签企业证书，陕西CA 展示陕西CA 企业证书，缺少的标记为未生成。
- 一键生成证书：按当前证书生成方式，为缺少证书或证书已过期的企业生成企业证书（自签时一并生成缺少的根证书），未过期的证书跳过，逐个企业返回结果。切换证书生成方式并保存后，存在缺少证书的企业时页面提示一键生成。
- 重新生成根证书：只能在根证书过期后操作；为该企业生成新的自签根证书，该企业的自签企业证书随之作废；该企业为当前签约企业时，自签个人证书一并作废。
- 查看证书：展示证书的主题、颁发者、序列号、有效期、状态、公钥、签名算法、密钥用法、是否为 CA、SHA-256 指纹与 PEM 内容。状态分为有效、待续签（进入续签期限）与已过期。
- 未过期的根证书与企业证书不能手动重新生成，到期前由自动续签处理。

存储与缓存：

- 企业资料与自签根证书路径存 `enterprise` 表，签章存签章目录下的 `<统一社会信用代码>.png`，企业证书记录存 `enterprise_certification` 表。
- 服务启动时把全部企业和企业证书记录加载到内存，签约只读内存；后台操作、证书签发与续签串行执行，先写数据库再刷新内存。
- 容器内可用 `./edocseal enterprise list` 查看企业与证书；新增、修改、切换与作废只在管理后台操作。

## 自签根证书

- 每个企业一张，主题 `CN=<企业名称> Root CA, O=<企业名称>, OU=<统一社会信用代码>, ST=<省份>, L=<城市>, C=CN`，有效期 99 年。
- 首次需要自签时自动生成，文件在证书目录的 `root/` 子目录，路径与过期时间记在企业记录上。
- 剩余有效期不足 30 天时重新生成。

## 企业证书

- 按「统一社会信用代码 + 生成方式」各保存一张，证书文件在证书目录的 `enterprise/` 子目录。
- 自签企业证书：由该企业的根证书签发，主题 `CN=<企业名称>, O=<企业名称>, OU=<统一社会信用代码>, ST=<省份>, L=<城市>, C=CN`，非 CA 证书，用途为数字签名与不可否认，有效期 10 年。
- 陕西CA 企业证书：配置了 `enterprise.url` 时从该地址按 `?code=<统一社会信用代码>` 拉取证书与私钥；未配置时用企业代办人信息直接向陕西CA 申请。
- 剩余有效期不足 7 天时重新签发。

## 个人证书

- 按身份证号查询未过期的证书记录（`certification` 表），有则直接复用，不区分签发方式；记录有效期为签发后 24 小时减 10 分钟。
- 没有可用证书时按生成方式签发，证书与私钥保存在证书目录的 `<身份证号>_cert.pem`、`<身份证号>_key.pem`，记录中的 `issuer` 列记下签发方式。
- 自签个人证书：由当前签约企业的根证书签发，主题 `CN=<身份证号>, O=<姓名>, OU=<身份证号>`，有效期 1 年。
- 陕西CA 个人证书：本地生成 RSA 私钥与 P10，向陕西CA 申请。

## 自动续签

- 签约时发现企业证书不存在或进入续签期限，先签发再签约；签发失败而旧证书尚未过期时继续使用旧证书。
- 定时任务每天凌晨 3 点检查全部企业：根证书剩余不足 30 天的重新生成；已有的企业证书（自签与陕西CA）剩余不足 7 天的重新签发。续签失败记录错误日志，下次检查或签约时再次尝试。

## 配置项

```yaml
selfSign: false            # 签约请求未携带生成方式时是否自签

dir:
  certificate: ./certificates   # 个人证书、企业证书与企业根证书目录
  seal: ./config                # 企业签章目录，为空时使用配置文件所在目录

enterprise:
  url: http://<正式机>:5015/enterprise/cert/<令牌>   # 测试机配置：陕西CA 企业证书从正式机拉取
  token: <令牌>                                      # 正式机配置：对外提供企业证书接口的令牌，为空时不提供
```

## 接口

- gRPC `ContractService.Sign`：签署合同，`certificate_issuer` 为证书生成方式。
- gRPC `EnterpriseService`：`List`、`Save`、`Delete`、`SetDefault`、`GenerateCertificates`、`RegenerateRootCertificate`，定义见 `pb/enterprise.proto`，出错时返回 `FailedPrecondition` 与错误原因。
- HTTP `GET /enterprise/cert/{token}?code=<统一社会信用代码>`：返回该企业的陕西CA 证书与私钥（PEM），`code` 为空时返回当前签约企业的；本机没有可用证书时先向陕西CA 申请。

## 环境与上线

- 只有正式机向陕西CA 申请企业证书；测试机配置 `enterprise.url` 从正式机拉取，避免重复申请真实证书。两台的令牌需一致。
- 新环境首次上线后，签约前必须在「签约证书」页面至少新增一个签约企业并上传签章，否则签约返回「未设置签约企业」。
